# PIIS UI-0 — Data Visualization Specification

> [!IMPORTANT]
> **Ground-Truth Data Visualization Rule:**
> Fabricated or hallucinated production metrics are strictly prohibited.
> When connected to live or simulated adapters, charts visualize actual ingested telemetry time-series and alarm counts. When telemetry is unavailable or sparse, charts explicitly display clean, empty, or abstention states rather than generating smoothing interpolations.

## 2. Detailed Chart Specifications

### 2.1 RF Telemetry Time-Series Chart (`TelemetryChart.tsx`)
- **Primary Objective:** Plot rolling RF metric observations (e.g. `vswr_ratio`, `packet_loss_rate`) against static and dynamic statistical thresholds.
- **Data Source:** `GET /api/v1/telemetry/timeseries?element_id={element_id}&metric_name={metric}`
- **Expected Data Schema:**
  ```json
  {
    "element_id": "GNB-RAN-701",
    "metric_name": "vswr_ratio",
    "unit": "ratio",
    "threshold_warning": 1.5,
    "threshold_critical": 2.0,
    "points": [
      {"timestamp": "2026-11-02T17:00:00Z", "value": 1.12, "is_anomaly": false},
      {"timestamp": "2026-11-02T17:30:00Z", "value": 2.45, "is_anomaly": true}
    ]
  }
  ```
- **Visual Design:**
  - Solid blue line (`#38bdf8`) for observed metric values.
  - Dashed red horizontal reference line (`#ef4444`) for critical threshold.
  - Red circular scatter points highlight timestamps where `is_anomaly=true`.
- **States:**
  - *Loading:* Animated SVG skeleton waveform.
  - *Empty:* "No telemetry observations recorded for element {id} in the selected time window."
  - *Error:* Amber warning banner detailing connection failure to Prometheus adapter.

### 2.2 Network Topology Adjacency Graph (`TopologyGraphView.tsx`)
- **Primary Objective:** Render the physical, logical, and service dependencies linking 5G RAN cell sites to 5G Core user planes.
- **Data Source:** `GET /api/v1/network/topology` (backed by `TelecomTopologyGraph`).
- **Epistemic Distinction Invariant:**
  - **Directly Impacted Elements (`[OBSERVED FACT]`):** Rendered as solid nodes with red alert borders (e.g. `GNB-RAN-701` emitting active VSWR alarms).
  - **Inferred Downstream Impact (`[HYPOTHESIS]`):** Rendered with dashed amber borders (e.g. downstream cell sectors or core UPF sessions potentially throttled).
- **Interactivity:**
  - Zoom, pan, and node click to inspect element telemetry and open correlated tickets.

### 2.3 Hypothesis Confidence Proxy Ranking (`HypothesesChart.tsx`)
- **Primary Objective:** Compare candidate root cause hypotheses generated by the investigation engine.
- **Data Source:** `POST /api/v1/incidents/{incident_id}/investigate` -> `ctx.hypotheses`.
- **Visual Representation:**
  - Horizontal bar chart plotting confidence scores ($0.00$ to $1.00$).
  - Amber bars (`#fbbf24`) explicitly marked with epistemic badge `[HYPOTHESIS — CANDIDATE ROOT CAUSE]`.
  - Bars below threshold ($< 0.50$) feature an adjacent "Low Confidence / Insufficient Evidence" alert flag.
- **Rule:** The chart header prominently displays: *"Model outputs are diagnostic hypotheses for human review; they are never autonomously confirmed root causes."*

---

### 2.4 Cryptographic Audit Sequence Timeline (`AuditSequenceTracker.tsx`)
- **Primary Objective:** Provide visual evidence of monotonic sequence continuity and hash-chain linkage.
- **Data Source:** `GET /api/v1/audit/records`.
- **Visual Representation:**
  - Linear sequence of cryptographic blocks connected by directional chain links.
  - Each block displays `#<sequence_number>`, the truncated SHA-256 digest (`386f...7abc`), operator ID, action badge (`APPROVE`/`REJECT`), and timestamp.
  - Hovering over a block displays the previous entry hash (`prev_hash`) and confirms mathematical link validity.
  - If a sequence gap or hash mismatch occurs, the chain link between the affected blocks turns bright red with a broken padlock icon and an alert: `DISCONTINUITY DETECTED AT SEQUENCE #N`.
