# PIIS UI-0 — Design System Specification

> [!IMPORTANT]
> **Aesthetic Stance: Anti-Slop Telecom NOC Engineering**
> Guided by `/taste` principles, PIIS rejects the generic "AI SaaS dashboard" tropes:
> - **NO** assistant palettes (no violet/cream/rust color schemes).
> - **NO** decorative gradient blobs, glowing blurred cards, or floating glassmorphic pills.
> - **NO** generic AI chatbot text or conversational conversational placeholders.
> - **NO** icon-topped identical feature cards or fake metric counters.
> - **INSTEAD:** High-density, disciplined telecom operations engineering aesthetic: dark-first command center with full light-theme parity, sharp contrast, clear typographic hierarchy, and unambiguous epistemic status demarcation.

---

## 1. Visual Epistemic Vocabulary (The 6 Standards)

Every data point, badge, card, and insight presented in the PIIS user interface must carry one of six explicit epistemic designations. These designations remain visually consistent across both Dark and Light themes:

| Epistemic Category | Semantic Meaning | Dark Mode Styling | Light Mode Styling | UI Badge Notation |
| :--- | :--- | :--- | :--- | :--- |
| **1. OBSERVED FACT** | Directly captured from telemetry exporters, hardware alarms, or raw tickets. | Ground: `rgba(2, 132, 199, 0.15)`<br/>Text: `#38bdf8`<br/>Border: `#0284c7` | Ground: `#f0f9ff`<br/>Text: `#0369a1`<br/>Border: `#bae6fd` | `[OBSERVED FACT]` |
| **2. MODEL PREDICTION** | Generated by machine learning models (triage routing, severity classifier). | Ground: `rgba(124, 58, 237, 0.15)`<br/>Text: `#c084fc`<br/>Border: `#7c3aed` | Ground: `#faf5ff`<br/>Text: `#6b21a8`<br/>Border: `#e9d5ff` | `[MODEL PREDICTION]` |
| **3. HYPOTHESIS** | Synthesized candidate root cause from RAG and topological correlation. | Ground: `rgba(217, 119, 6, 0.15)`<br/>Text: `#fbbf24`<br/>Border: `#d97706` | Ground: `#fffbeb`<br/>Text: `#b45309`<br/>Border: `#fde68a` | `[HYPOTHESIS]` |
| **4. RECOMMENDATION** | Actionable diagnostic SOP retrieved from historical runbooks. | Ground: `rgba(5, 150, 105, 0.15)`<br/>Text: `#34d399`<br/>Border: `#059669` | Ground: `#f0fdf4`<br/>Text: `#15803d`<br/>Border: `#bbf7d0` | `[RECOMMENDATION]` |
| **5. HUMAN-APPROVED DECISION** | Cryptographically signed action authorized by an authenticated human operator. | Ground: `rgba(13, 148, 136, 0.15)`<br/>Text: `#2dd4bf`<br/>Border: `#0d9488` | Ground: `#f0fdfa`<br/>Text: `#0f766e`<br/>Border: `#99f6e4` | `[HUMAN-APPROVED DECISION]` |

## 2. Design Tokens: Dark & Light Parity

### 2.1 Surface & Background Tokens

```css
:root {
  /* LIGHT THEME (Enterprise Operations) */
  --bg-app: #f8fafc;            /* Clean paper ground */
  --bg-surface: #ffffff;        /* Primary card surface */
  --bg-subtle: #f1f5f9;         /* Inset boxes, table headers */
  --border-subtle: #e2e8f0;     /* Hairline borders */
  --border-strong: #cbd5e1;     /* Focus rings & active tabs */
  
  --text-primary: #0f172a;      /* 100% full ink running text */
  --text-secondary: #475569;    /* Secondary notes & labels */
  --text-muted: #64748b;        /* Timestamps, footnotes */

  --primary-accent: #0284c7;    /* NOC blue action tone */
  --primary-hover: #0369a1;
}

[data-theme="dark"] {
  /* DARK THEME (NOC Command Center) */
  --bg-app: #0b1120;            /* Deep naval night */
  --bg-surface: #111c30;        /* Card surface */
  --bg-subtle: #0f172a;         /* Table headers, code blocks */
  --border-subtle: #1e293b;     /* Structural borders */
  --border-strong: #334155;     /* Interactive borders */
  
  --text-primary: #f8fafc;      /* Crisp high-contrast white */
  --text-secondary: #94a3b8;    /* Muted metadata */
  --text-muted: #64748b;        /* De-emphasized notes */

  --primary-accent: #38bdf8;    /* High-visibility cyan */
  --primary-hover: #0284c7;
}
```

### 2.2 Severity & Operational Status Tokens

```css
:root, [data-theme="dark"] {

```

## 3. Typography & Hierarchy

- **Font Family:** Standard native system font stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`.
- **Monospace Family:** Native tabular code stack for hashes, IDs, and timestamps: `ui-monospace, SFMono-Regular, "Roboto Mono", Menlo, Consolas, monospace`.
- **Typographic Scale:**
  - `Display Title (H1)`: 1.25rem (20px), font-weight 700, line-height 1.2.
  - `Section Header (H2)`: 1.05rem (16.8px), font-weight 600, line-height 1.3.
  - `Card Header (H3)`: 0.9rem (14.4px), font-weight 600, text-transform uppercase, letter-spacing 0.5px.
  - `Body Text`: 0.85rem (13.6px), font-weight 400, line-height 1.5.
  - `Captions & Tags`: 0.75rem (12px), font-weight 500, tabular figures enabled (`font-variant-numeric: tabular-nums`).

## 4. Accessibility & Interaction Specifications (WCAG 2.1 AA)

1. **Color Contrast:**
   - All body text against surface backgrounds maintains a minimum contrast ratio of **7:1** (AAA standard).
   - All epistemic badges and severity indicators maintain a minimum contrast ratio of **4.5:1** against their background tints.
2. **Focus Visibility:**
   - Interactive elements (buttons, table rows, form inputs, tabs) display an explicit 2px solid focus ring (`outline: 2px solid var(--primary-accent); outline-offset: 2px`) upon keyboard `Tab` focus.
3. **Screen Reader Semantic Support:**
   - Tables utilize standard `<thead>`, `<tbody>`, `<th> scope="col"`, and accessible captions.
   - Status indicators feature visually hidden descriptive text (`<span class="sr-only">Status: Critical</span>`).
   - Modals use Radix UI `Dialog.Root` which handles focus trapping, `Escape` key dismissal, and restores focus to the trigger button upon closure.
